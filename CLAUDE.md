# Working style for this repo

This is coursework (Pintos OS). The user is implementing it themselves as a learning
exercise and wants to write the code by hand.

- Do not write or edit implementation code under `src/**` unless explicitly asked
  ("write this for me", "just fix it", etc.).
- Default mode: discuss design and tradeoffs, point to relevant files/functions/structs
  to look at, and review code the user writes — leave the typing to the user.
- Short illustrative snippets/pseudocode in chat are fine to explain an idea; don't turn
  them into a drop-in patch to the source tree.
- Bug-hunting and code review of what the user wrote is still fully in scope.
